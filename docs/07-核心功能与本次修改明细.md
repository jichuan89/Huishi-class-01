## 4. 手势翻页、左右手和摄像头

### 4.1 左右手纠正

位置：`D:\jjr\shuzhi-class\components\HandController.tsx`。

MediaPipe handedness 使用原始 Left/Right，不再因镜像预览额外交换。左手负责缩放与课件翻页，右手负责模型操作。镜像是显示坐标处理，不是生理左右手转换。翻页动作期间抑制左手缩放；单手模式还会清除冲突旋转。

新增状态：starting、ready、tracking、no-hand、error；error 可携带 message。Worker、摄像头错误和重试状态传给课堂页面，重试通过组件 revision 重挂载。测验使用实际检测到的第一只手关键点，不能直接套普通模型控制的锁手规则。

### 4.2 翻页识别参数

位置：`D:\jjr\shuzhi-class\services\coursewareSwipe.ts`、
`D:\jjr\shuzhi-class\services\coursewareSwipeInput.ts`。

只接收置信度至少 0.75、已锁定且非 stale 的 Left 手；目标确认时间 180ms。食指和中指并拢后水平滑动，预览向左上一页、向右下一页。

| 参数 | 值 | 单位/含义 |
|---|---:|---|
| directionDistance | 0.02 | 归一化方向确认距离，结合宽高比修正 |
| straightAngle / parallelAngle | 140 / 35 | 角度，伸直及平行判定 |
| joinEnter / joinExit | 0.38 / 0.54 | 指尖距离与掌宽比；进入/退出滞回 |
| confirmMs | 80 | 姿态确认时间 ms |
| minMoveMs / maxMoveMs | 100 / 800 | 有效滑动时间窗 ms |
| gapMs / missingGraceMs | 160 / 100 | 帧间隔和短漏检容忍 ms |
| palmDistance / screenDistance | 0.40 / 0.04 | 掌宽比例及归一化屏幕距离条件 |
| horizontalRatio | 1.5 | 水平位移优势判定 |
| cooldownMs | 600 | 翻页冷却 ms |
| settleMs / settleRadius | 180 / 0.09 | 重新待命的稳定时间和半径 |
| smoothingMs | 30 | 时间感知平滑 ms |

状态为 preparing → ready → sliding → triggered → rearming。反向、明显斜移、超时或换手取消旧动作；短漏检保留已观察位移，但恢复帧的跳跃不累计。一划只能触发一次，回程和持续来回摆动不能重复翻页。测验、禁用翻页或 watchdog 时清理状态。

### 4.3 摄像头位置和拖动

位置：`D:\jjr\shuzhi-class\components\DraggableCamera.tsx`。课堂模型/互动内容且 cameraActive 时挂载。

sessionStorage 键 `classroom-camera-position`，不是按用户隔离。x/y 为父容器相对 CSS 像素；maxX = 父宽 - 摄像头宽 - 8，maxY = 父高 - 摄像头高 - 84；默认 x 为 maxX - 16 后钳制，y 为 maxY。父容器或自身尺寸变化通过 ResizeObserver 重新钳制并清理拖动状态。

仅左键触发拖动，按钮区域不启动拖动；采用 pointer capture，并阻止点击、滚轮等向课堂模型冒泡。测验时 hidden 只切换 CSS 隐藏，不代表释放摄像头流。

入口：备课模型弹窗/建模工作区。Python 当前 `generate_image_model` 固定使用 Hunyuan，返回原始 GLB；parts 为空、anatomyDisplayAvailable=false、engine=hunyuan3d，医学语义需人工审核。四视图未 ready 时进入 needs_review，而不是宣称全流程完成。旧演示模型生成入口已拒绝，不能靠旧 demo 回退制造成功结果。

| UI 参数 | 当前默认/可选 | 实际链路注意事项 |
|---|---|---|
| textureResolution | 字符串 1024；512/768/1024/1536/2048 | 前端提交 texture_resolution |

模型查看器兼容旧双层模型时隐藏 Anatomy、Anatomy_ 前缀、userData.layer=anatomy 或 semantic=true 的对象，以显示原外观，不是为新模型自动生成解剖层。
