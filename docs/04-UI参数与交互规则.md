# 数智课堂项目交接（四）

## UI 参数与交互规则

更新日期：2026-10-13

本文档记录页面控件的实际位置、参数名、类型、默认值、显示条件、操作规则和下游影响。页面路由和组件关系见 `03-页面与路由交接.md`。

## 1. 参数说明规则

| 字段 | 含义 |
|---|---|
| 页面位置 | 控件在页面中的区域或标签 |
| 参数名 | React state、表单字段或传给子组件的字段 |
| 类型 | TypeScript 或接口使用的类型 |
| 默认值 | 新建页面或首次进入时的值 |
| 显示条件 | 控件什么时候出现或生效 |
| 交互结果 | 用户操作后的状态变化 |
| 数据去向 | 该值最后进入的业务对象、接口或页面 |

### 2.4 手势速度参数

位置：课堂设置面板；代码位置约为 `Dashboard.tsx` 的速度设置区域。

| 控件 | state | 类型 | 范围 | 默认值 | 修改后的影响 |
|---|---|---|---:|---:|---|
| 缩放速度 | `zoomSpeedMultiplier` | number | `0.1 - 5.0` | `0.8` | 影响左手缩放速度 |
| 旋转速度 | `rotationSpeedMultiplier` | number | `0.1 - 5.0` | `5.0` | 影响右手旋转速度 |
| 恢复默认 | 两个 state 同时更新 | - | - | 缩放 `0.8`、旋转 `1.0` | 注意：代码中的恢复默认按钮将旋转值重置为 `1.0`，与首次 state 默认值 `5.0` 不一致，交接人员修改时需保持或统一该行为 |

手势基础规则：

- 左手主要用于缩放。
- 右手主要用于旋转和拆解拖动。
- 右手食指/中指捏合触发旋转连续性和拖拽会话。
- 松开后旧零件立即固定，必须重新捏合才会抓取新零件。
- 摄像头无结果超过 watchdog 时间后清理旧旋转、缩放、拖拽和虚拟手状态。

### 3.2 课程与教材步骤

位置：新建教案的第 1 步“课程信息”。

| 字段 | 类型 | 默认值 | 显示和影响 |
|---|---|---|---|
| 学段 | 固定文本 | `本科` | 当前不可自由切换 |
| `field` 专业名称 | string | `生物医学` | 进入课程定位和专业能力目标 |
| `courseName` 课程名称 | string | `人体解剖学与生理学` | 写入课程画像 |
| `topic` 课程课题 | string | 空 | 必填；决定教案主题、模型和课件内容 |
| `textbookVersion` | string | 空 | 教材版本 |
| `chapter` | string | 空 | 章节 |
| `unitPosition` | string | `结构与功能` | 单元定位 |
| `teachingScene` | string | `日常课堂` | 教学场景 |
| `duration` | select | `40` | 可选 `40/80/120` 分钟 |
| `lessonCount` | select | `1` | 可选 `1/2/3` 节 |

课时联动规则：

```text
1 节 -> 40 分钟
2 节 -> 80 分钟
3 节 -> 120 分钟
```

修改节数会同步总时长；修改总时长也会反向同步节数。

## 4. 3D 模型生成和导入面板

位置：备课工作台 `model` 阶段或输出结果的“3D 模型”标签。

### 4.1 生成模式

| 控件 | 参数 | 默认值 | 说明 |
|---|---|---|---|
| 单张图片生成 | `mode='single'` | `single` | 使用一张输入图；页面显示单图质量提示 |
| 四视角生成 | `mode='multiview'` | `single` | 接收 front/left/right/back 四张图，适合多视图配准 |

### 4.2 模型生成选项

| 参数 | 类型 | 默认值/选项 | 作用 |
|---|---|---|---|
| `textureResolution` | string | 由面板选项提供 | 生成模型纹理分辨率 |
| `foregroundRatio` | string | 由面板选项提供 | 输入图前景占比 |
| `vertexCount` | string | 由面板选项提供 | 目标顶点或面数级别 |
| `removeBackground` | boolean | 面板默认值 | 是否去除输入图背景 |
| `separationMode` | `'geometric' \| 'anatomical'` | 面板默认值 | 几何拆分或解剖语义拆分 |
| `modelFile` | File/null | `null` | 单张输入图片或导入模型文件 |
| `modelViews` | `Partial<Record<'front'\|'left'\|'right'\|'back', File>>` | `{}` | 四视角输入文件 |

生成状态：

```text
idle -> generating -> generated
                   -> needs_review
                   -> failed/unavailable
```

页面必须按真实状态显示“生成中、已生成、需要检查、失败或不可用”，不能用内置示例模型伪装真实生成结果。

### 4.3 导入模型

支持模型格式：`GLB / GLTF / FBX`。

导入后：

- `source='imported'`。
- 显示模型预览和下载入口。
- 不自动生成语义拆解部件。
- 可以用于观察和课件展示。
- 如果没有可持久化的导出地址，不能直接用于 PPTX 生成。

## 6. 互动课件故事板参数

文件：`prep/CoursewareStoryboard.tsx`。

位置：结果标签“互动课件”。

| 控件 | 参数 | 默认/范围 | 交互结果 |
|---|---|---|---|
| 桌面预览 | `mobile=false` | 默认桌面 | 使用桌面布局预览 |
| 移动预览 | `mobile=true` | 关闭 | 使用移动布局预览 |
| 当前场景 | `selectedId` | `'scene-01'` | 左侧场景轨道点击后切换 |
| 场景启用 | `scene.enabled` | 由生成清单决定 | 停用场景不会进入课堂播放 |
| 前移/后移 | 场景数组位置 | 当前顺序 | 更新 `manifest.scenes` 顺序并增加 revision |
| 场景重做 | `sceneId` | 当前场景 | 调用重新生成接口，只替换当前场景 |
| 保存 | `busy='save'` | 空闲 | 持久化当前清单 |
| 配套演示文稿 | `busy='pptx'` | 空闲 | 先准备模型视图，再导出 PPTX |
| 离线课件 | `busy='zip'` | 空闲 | 导出 HTML、模型、数据和资源 ZIP |

可编辑场景字段：

- 标题 `scene.title`。
- 教学主张 `scene.claim`。
- 学生操作 `scene.studentAction`。
- 预期产出 `scene.expectedOutput`。
- 学习内容 `scene.detail.learningContent`。
- 评价证据 `scene.detail.evidence`。
- 未达标补救 `scene.detail.remediation`。
- 布局 `scene.layout`。
- 动画或运动参数 `scene.motion`。

编辑后：

- `source` 变为 `teacher-edited`。
- `revision` 加 1。
- `status` 变为 `draft`。
- 导出前必须使用当前最新清单。

## 7. 课堂课件运行时参数

文件：`components/InteractiveCourseware.tsx`。

| 参数/状态 | 类型 | 默认值 | 作用 |
|---|---|---|---|
| `index` | number | `0` | 当前场景索引 |
| `hidden` | `Set<string>` | 空集合 | 已隐藏模型部件 |
| `isolated` | string/null | `null` | 当前隔离的部件 |
| `selected` | string/null | `null` | 当前选中部件 |
| `explosion` | number | 当前场景配置或 `0` | 模型拆解强度 |
| `flowStep` | number | `0` | 血流路径当前步骤 |
| `reducedMotion` | boolean | 由系统偏好决定 | 是否关闭场景过渡动画 |

运行规则：

- 上一步/下一步改变 `index`。
- 进入新场景时根据场景模型配置重置隐藏、隔离、选中和拆解状态。
- 血流场景点击“下一段血流”递增 `flowStep`，到末尾后循环。
- 练习场景只有在 `quizAvailable` 为真时显示开始练习按钮。
- 退出课件调用 `onExit()`，返回普通模型内容。
- 课堂摄像头启用时，互动课件可以接收左右翻页手势。

## 8. 预热题编辑器参数

位置：结果标签“练习题”。

每次默认生成 5 道题，页面显示 `启用题数/5`。

每道题可编辑：

| 字段 | 类型 | 交互 |
|---|---|---|
| `id` | string | 系统生成，不建议手动改 |
| `enabled` | boolean | 复选框控制是否进入课堂 |
| `question` | string | 编辑题干 |
| `options` | string[] | 编辑 A、B、C、D 等选项 |
| `correctIndex` | number | 单选正确答案 |
| `explanation` | string | 编辑答案解析 |

“重新生成本题”只替换当前题目。教师手动修改不会被后续模型同步覆盖，除非主动重新生成该题。

## 9. 管理员页面参数

文件：`AdminUsers.tsx`。

初始标签：`activeTab='users'`。

| 标签 | 参数 | 默认值 | 关键操作 |
|---|---|---|---|
| 用户 | `activeTab='users'` | 默认 | 查看用户、修改角色、启用/停用、打开用户日志 |
| 日志 | `activeTab='logs'`、`logsPage` | 第 1 页，每页 50 | 翻页、按用户查看日志、刷新 |
| 资源 | `activeTab='resources'` | - | 进入 `AdminResourceLibrary` |
| 反馈 | `activeTab='feedback'`、`feedbackPage` | 第 1 页，每页 20 | 翻页、查看反馈和附件、刷新 |

管理员页面只有 `role='admin'` 时由 `App` 渲染。普通用户不能通过前端状态直接获得管理员页面，服务端接口仍需进行权限校验。

## 10. 参数修改后的影响范围

| 修改位置 | 直接影响 | 需要同步检查 |
|---|---|---|
| `FormState` 字段 | 教案生成请求 | Python 教案 schema、保存记录、导出 |
| `ModelOptions` | 3D 生成请求 | Node 代理、Python 生成参数、结果状态 |
| `CoursewareManifest` 场景字段 | 故事板和课堂播放 | PPTX 导出、ZIP 导出、Dashboard 应用课程 |
| `WarmupQuestion` | 课堂答题 | QuizOverlay、错题记录、课堂事件 |
| `zoomSpeedMultiplier`/`rotationSpeedMultiplier` | 3D 手势表现 | `ControlRefs`、ModelViewer、性能验收 |
| `activeContent`/`workspaceMode` | 页面展示 | 摄像头、详情面板、课件和模型生命周期 |
| 管理员分页参数 | 管理台列表 | Node API 分页参数和总页数计算 |

修改 UI 参数时必须同时检查：

1. 页面 state 的默认值。
2. 控件的取值范围和选项。
3. 提交函数中的字段映射。
4. Node 代理请求体。
5. Python 服务解析和返回字段。
6. 页面在加载、生成中、成功、失败和回退状态下的显示。
