## 6. 部署参数与运行边界

配置模板位置：`D:\jjr\shuzhi-class\.env.example`；变量详表见第 02 部分，本章只强调上线差异。

| 参数 | 当前开发值/行为 | 上线要求 |
|---|---|---|
| API_PORT | 4000 | 反向代理 API 指向一致 |
| CLIENT_ORIGIN | http://localhost:3000 | 改实际 HTTPS 源，含端口，核验 TTS WebSocket 来源 |
| MYSQL_PORT / DATABASE | 模板 3307/shuzhi_classroom；源码回退 3306/huishi_classroom | 显式配置，避免连错库 |
| JWT_SECRET / ADMIN_PASSWORD | 存在开发回退 | 使用受控秘密并修改默认管理凭据 |
| TEACHER_STUDIO_SERVICE_URL | 127.0.0.1:8765 | 与 Python host/port 一致，内部服务不直接公网暴露 |
| TEACHER_STUDIO_AUTOSTART | 除 false 外尝试启动 | 进程管理已启动 Python 时设 false 防重复 |
| TEACHER_STUDIO_PYTHON | D:\jjr\.venv\Scripts\python.exe | 改部署机器真实解释器路径 |
| HUNYUAN3D_BASE_URL / MODEL | https://tokenhub.tencentmaas.com / hy-3d-3.1 | 核验供应商网络、鉴权和实际任务完成 |
| HUNYUAN3D_API_KEY | 模板为空 | 仅服务端配置，不写入前端及文档 |
| TRUST_PROXY_HOPS | 源码按环境解析 | 按实际代理层数核验，防错误信任来源 |

生产需单独托管 dist 静态资源并转发 /api 和 WebSocket；npm start 只启动 Node，不等于 Vite 或完整生产站点。局域网 HTTP 地址通常不是摄像头允许的安全上下文，课堂摄像头部署要用 HTTPS 或 localhost。

现有 `D:\jjr\shuzhi-class\scripts\deploy.py` 面向 Linux /www/wwwroot/shuzhi、PM2 名 shuzhi、nginx，依赖 paramiko，凭据取 SSH_HOST/SSH_USER/SSH_PASS。脚本做 git 快进、构建与服务重启，不会自动交付当前未提交/未跟踪内容，也不证明 Windows PowerPoint 动画能力被部署。接手前审阅命令及主机身份校验；本次未调用它。

## 7. 数据备份与回滚

|---|---|---|
| 业务记录 | MySQL，包括 lesson_plans、user_models、user_model_jobs | 使用数据库备份；验证可恢复及用户归属 |

| 应用上下文/摄像头位置 | localStorage/sessionStorage | 不是完整教案或模型备份；blob URL 不可长期恢复 |
| 配置 | 部署机器秘密配置 | 安全渠道备份，不进仓库或交接 Markdown |
