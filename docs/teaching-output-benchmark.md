## 硬性产出标准

1. 课堂主线采用“情境钩子 → 预测/选择 → 观察/操作 → 概念建构 → 即时反馈 → 迁移应用 → 回扣反思”。
2. 教案每个环节必须包含教师行为、学生动作、可见产出和评价证据。
3. PPT 每页只承担一个教学任务，每三页至少有一次学生可执行动作。
4. 数学和理科优先提供参数、图形、模型或实验变量；语言类优先提供角色与真实沟通任务。
5. 练习页与答案页分开，答案说明依据，并允许学生修订。
6. 结尾必须回到开课问题，并提供真实情境迁移或可提交作品。
7. 所有生成文字、形状、图表保持可编辑；公开案例只作为来源说明，不嵌入其素材。
