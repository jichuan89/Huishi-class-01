# 数智课堂项目交接（二）

## 系统架构与启动配置

更新日期：2026-10-13

项目目录：`D:\jjr\shuzhi-class`

## 1. 系统拓扑

```text
浏览器 3000
  -> Vite 前端开发服务器
  -> /api 代理到 Node API 4000
  -> Node/Express API + TTS WebSocket
       -> MySQL 3307
       -> Teacher Studio 8765
            -> 教案、题目、课件、导出和模型服务
            -> Ollama、Blender、PDF 等本地工具
```

开发环境中浏览器首先访问 3000，不能直接把 4000 或 8765 当作前端地址。

## 2. 服务和端口

| 服务 | 默认地址 | 端口 | 启动文件 | 主要用途 |
|---|---|---:|---|---|
| Web 前端 | `http://127.0.0.1:3000/` | 3000 | Vite、`vite.config.ts` | React 页面和静态资源 |
| Node API | `http://127.0.0.1:4000/` | 4000 | `server/index.js` | 登录、业务接口、数据库、代理、TTS |
| Teacher Studio | `http://127.0.0.1:8765/` | 8765 | `teacher-studio-service/backend/server.py` | 教案、课件、模型和导出 |
| MySQL | `127.0.0.1:3307` | 3307 | `scripts/start_local.py` | 数据库存储 |
| Ollama | `http://127.0.0.1:11434/` | 11434 | 外部程序 | 本地文案增强，可选 |

Vite 固定使用 3000 并启用 `strictPort`；Node 从 `API_PORT` 读取，默认 4000；Python 从 `TEACHER_STUDIO_PORT` 读取，默认 8765。本地启动器使用 MySQL 3307。

## 3. 一键启动

```powershell
Set-Location D:\jjr\shuzhi-class
& 'D:\jjr\.venv\Scripts\python.exe' 'D:\jjr\shuzhi-class\scripts\start_local.py'
```

启动器会检查或启动 MySQL、准备本地配置、启动 Python 服务、Node API 和 Vite。

启动后检查：

```text
前端：http://127.0.0.1:3000/
Node：http://127.0.0.1:4000/api/health
Teacher Studio：http://127.0.0.1:8765/api/local-model/status
```

## 4. 手动启动

### 4.1 Python Teacher Studio

```powershell
Set-Location D:\jjr\shuzhi-class\teacher-studio-service\backend
& 'D:\jjr\.venv\Scripts\python.exe' server.py
```

默认监听 `127.0.0.1:8765`。修改 `TEACHER_STUDIO_HOST` 或 `TEACHER_STUDIO_PORT` 后，必须同步修改 Node 的 `TEACHER_STUDIO_SERVICE_URL`。

### 4.2 Vite 前端

```powershell
Set-Location D:\jjr\shuzhi-class
& 'C:\Program Files\nodejs\node.exe' node_modules/vite/bin/vite.js --host 0.0.0.0 --port 3000 --strictPort
```

`vite.config.ts` 关键参数：

| 参数 | 当前值 | 作用 |
|---|---|---|
| `server.port` | `3000` | 前端端口 |
| `server.host` | `0.0.0.0` | 允许局域网访问 |
| `server.strictPort` | `true` | 端口冲突时直接失败 |
| `proxy['/api'].target` | `http://localhost:${API_PORT}` | API 转发目标 |
| `proxy['/api'].ws` | `true` | 支持 TTS WebSocket |
| `watch.ignored` | generated/storage | 避免生成文件触发重载 |

### 4.3 Node API

```powershell
Set-Location D:\jjr\shuzhi-class
& 'C:\Program Files\nodejs\node.exe' server/index.js
```

Node 启动时读取 `.env.local`，连接或初始化 MySQL，检查 Teacher Studio，并在 `TEACHER_STUDIO_AUTOSTART=true` 时尝试自动启动 Python 服务。

## 5. 配置文件和安全边界

配置模板是 `D:\jjr\shuzhi-class\.env.example`；本地配置通常是 `D:\jjr\shuzhi-class\.env.local`。

交接文件中不得写入以下实际值：

- `JWT_SECRET`。
- `HUNYUAN3D_API_KEY`。
- 数据库密码。
- 管理员密码。
- 用户上传模型、图片和课件。

## 6. 环境变量参数

### 6.1 Web、Node 和权限

| 变量 | 类型 | 默认值 | 位置/作用 |
|---|---|---|---|
| `API_PORT` | number | `4000` | Node 端口，同时决定 Vite API 代理目标 |
| `CLIENT_ORIGIN` | string | `http://localhost:3000` | CORS 和 TTS 来源校验 |
| `JWT_SECRET` | string | 有开发回退值 | 登录 Token 签名；生产必须覆盖 |
| `NODE_ENV` | string | 未设置 | 开发/生产行为判断 |
| `TRUST_PROXY_HOPS` | number/string | 按环境计算 | 反向代理配置 |
| `ADMIN_USERNAME` | string | `admin` | 初始化管理员名 |
| `ADMIN_PASSWORD` | string | 开发默认值 | 初始化管理员密码，生产必须修改 |

### 6.2 MySQL

| 变量 | 类型 | 默认值 | 作用 |
|---|---|---|---|
| `MYSQL_HOST` | string | `localhost` | 数据库主机 |
| `MYSQL_PORT` | number | `3306`；本地启动器为 `3307` | 数据库端口 |
| `MYSQL_USER` | string | `root` | 数据库用户 |
| `MYSQL_PASSWORD` | string | 空 | 数据库密码 |
| `MYSQL_DATABASE` | string | `huishi_classroom`；本地启动器为 `shuzhi_classroom` | 数据库名 |

本地启动器连接：

```text
host: 127.0.0.1
port: 3307
database: shuzhi_classroom
```

部署到已有 MySQL 时，以实际数据库和账号权限为准。

### 6.3 Teacher Studio

| 变量 | 类型 | 默认值 | 作用 |
|---|---|---|---|
| `TEACHER_STUDIO_SERVICE_URL` | URL | `http://127.0.0.1:8765` | Node 代理目标 |
| `TEACHER_STUDIO_AUTOSTART` | boolean/string | 开启 | Node 是否自动启动 Python |
| `TEACHER_STUDIO_PYTHON` | path | 当前 Python 或系统 Python | Python 解释器 |
| `TEACHER_STUDIO_ROOT` | path | 项目下 `teacher-studio-service` | Python 服务根目录 |
| `TEACHER_STUDIO_HOST` | string | `127.0.0.1` | Python 监听地址 |
| `TEACHER_STUDIO_PORT` | number | `8765` | Python 监听端口 |

### 6.4 3D 和本地模型

| 变量 | 类型 | 默认值 | 作用 |
|---|---|---|---|
| `HUNYUAN3D_BASE_URL` | URL | 无安全默认值 | 图生 3D 服务地址 |
| `HUNYUAN3D_API_KEY` | string | 空 | 图生 3D 凭证 |
| `HUNYUAN3D_MODEL` | string | `hy-3d-3.1` | 使用的模型 |
| `OLLAMA_BASE_URL` | URL | `http://127.0.0.1:11434` | Ollama 地址 |
| `OLLAMA_MODEL` | string | `qwen3:4b` | 本地文案模型 |

Ollama 不可用、模型未安装或结果校验失败时，服务回退内置模板；页面应显示实际来源，不能把模板结果标成 AI 成功生成。

## 7. 请求代理规则

```text
浏览器 3000/api/...
  -> Vite proxy
  -> Node 4000/api/...
```

| 路径前缀 | 处理方式 | 目标 |
|---|---|---|
| `/api/auth/*` | Node 自处理 | 登录、注册、当前用户 |
| `/api/admin/*` | Node 自处理 | 用户、资源、管理操作 |
| `/api/classroom/*` | Node/数据库 | 课堂数据和事件 |
| `/api/prep/*` | 认证后代理 | Teacher Studio |
| `/api/courseware/*` | 认证后代理 | Teacher Studio |
| `/api/3d/*` | 按路由处理 | 3D 任务 |
| TTS WebSocket | Node WebSocket | 语音服务 |

修改接口时必须同时检查：前端调用路径、Node 路由/代理、Python 路由和字段。

## 8. 启动排查

页面打不开：

```powershell
Invoke-WebRequest http://127.0.0.1:3000/
```

页面能打开但接口失败：

```powershell
Invoke-WebRequest http://127.0.0.1:4000/api/health
```

备课生成失败：

```powershell
Invoke-WebRequest http://127.0.0.1:8765/api/local-model/status
```

随后确认 Python 服务、`TEACHER_STUDIO_SERVICE_URL`、Ollama、Blender、PDF/PPTX 依赖是否可用。

4000 已占用时，先调用健康检查确认已有服务是否正常；正常时不要重复启动。确需换端口时，同时修改 `API_PORT`、Vite 代理目标、`CLIENT_ORIGIN` 和检查地址。

## 9. 当前部署限制

- 本地开发默认依赖 Windows 路径和 `D:\jjr\.venv` Python 环境。
- 启动器默认寻找 `C:\Program Files\MySQL\MySQL Server 9.5`。
- Ollama、Hunyuan 3D、Blender 和 PDF 解析不是纯前端能力，部署时必须单独确认。
- `.env.example` 只是变量名和示例值，不代表生产配置。
- 生产环境必须替换 JWT secret、管理员密码和第三方 API Key。
- 页面参数、数据字段和 API 请求体分别记录在第 4、5、6 份文档中。
