## 2. 通用请求约定

### 2.1 认证和内容类型

- Node 的业务接口使用 `requireAuth`，管理员接口另用 `requireAdmin`。用户归属以服务器 `req.user.id` 为准。
- 前端同源 fetch 默认携带同源 Cookie；已有很多调用显式使用 `credentials: 'include'`。
- JSON 请求设置 `Content-Type: application/json`。Express JSON 上限为 `12mb`（`server/index.js:197`）。
- FormData 请求由浏览器生成 multipart boundary，调用方不应手动固定 Content-Type。
- Python POST 要求 Content-Length 大于 0；`/api/3d/*` 请求上限 75 MiB，其余 POST 上限 20 MiB。具体上传接口还有更小的文件限制。
- `204` 返回没有 JSON；不能对所有成功响应无条件调用 `response.json()`。

### 2.2 Python 代理映射

实现：`server/index.js:1204` 的 `proxyTeacherStudioRequest`；挂载在 `1249`。

```text
浏览器 /api/prep/lesson-design/generate-draft
  -> Node 验证登录
  -> Python /api/lesson-design/generate-draft

浏览器 /api/prep/courseware/export-pptx
  -> Python /api/courseware/export-pptx
```

代理去掉 `/prep` 并保留剩余路径和查询字符串；转发 content-type、content-length、accept。JSON 会重新序列化，multipart 则转发原始流。

返回 JSON 会递归将 `/api/3d/`、`/api/ppt/`、`/api/assets/`、`/api/courseware/` 地址改成浏览器可访问的 `/api/prep/...`。二进制文件直接流式返回。

`/api/3d/generate*` 使用自定义长请求传输，socket 超时为 20 分钟；其他代理请求使用 fetch。代理连接 Python 失败返回 `502 {error}`。20 分钟不是所有 API 的统一超时。

### 2.3 错误响应

| 状态 | 含义/实例 | 响应字段 |
|---|---|---|
| 400 | 参数无效、教案未审核、课件质检阻断 | Node 常用 `message`；Python 常用 `error`，可能带 `quality` |
| 401 | 未登录、登录账号或角色不匹配 | `message` |
| 403 | 无权限、账号停用 | `message` |
| 404 | 用户模型、课件、文件不存在或不属于当前用户 | `message` 或 `error` |
| 409 | 用户名重复、标签仍有模型、模型没有可重处理源图 | `message` |
| 410 | 内置生物医学模型生成已停用 | `error` |
| 413 | 请求/文件超限；Python 也对空 POST body 使用该状态 | `message` 或 `error` |
| 415 | 用户模型上传不是 multipart | `message` |
| 500 | Python 执行异常或 Node 未处理异常 | `error` 或 `message` |
| 502 | Node 无法连接备课服务 | `error` |
| 503 | 教师版 AI 成稿没有有效 draft | `draft:null`、`generation`、`quality` |

前端展示错误应兼容 `data.error || data.message`。HTTP 200 也可能带 `quality.blocking` 或 `needs_review`，需要检查业务状态。

### 6.3 模型四视图准备

`services/coursewareExport.ts` 先提交 `checkOnly:true`。若返回 missing，再提交 false。只有 ready 或 not-required 才进入导出；ready 必须具备 front/left/right/back 四个 URL。

| 返回字段 | 类型/含义 |
|---|---|
| `status` | missing / ready / not-required，视课程是否需要模型而定 |
| `viewImageUrls` | 四个方向的图片地址 |
| `viewModelFingerprint` | 原模型 SHA-256，防止模型换了还复用旧图片 |
| `viewRenderVersion` | 当前标准渲染版本，model_views 中为 orthographic-v1 |

| POST `/api/models/import` | multipart，多个 files，primaryFileName | 201 `{model}` |

导入允许 GLB/GLTF/FBX 主文件和允许列表内的纹理/二进制附件，最多 64 个文件，总计 260 MiB，不能空文件、不能重复文件名，primaryFileName 必须匹配主文件。

model 结果由 privateModelPayload 构造，包含 id、name、mode、status、source、modelUrl、modelType、assetUrls、部件/质量信息及各下载 URL。文件 type 可包含 model、glb、appearance、blend、preview、view-front/left/right/back 和 manifest.files 内的附件 key；最终仍按允许扩展名和所有权校验。

### 11.3 TTS WebSocket

入口 `/api/tts`，Vite 的 /api 代理配置 ws=true。升级连接时检查 Cookie 身份和允许来源；语音偏好从 /api/voice/preferences 读取。具体帧格式应直接按 `server/volcTts.js` 和 `services/xiaozhiSpeechService.ts` 对照，不应使用 HTTP fetch JSON 替代 WebSocket。

客户端控制消息使用 JSON 文本：`{type:"start",speaker?:string}` 开始，`{type:"text",text:string}` 推送文本，`{type:"finish"}` 完成，`{type:"cancel"}` 取消。连接消息上限 64 KiB，客户端二进制消息会被关闭（1003）；无效 JSON 为 1007，重复 start 为 1008。未登录返回 error 消息后以 1008 关闭；音频返回可包含二进制，不能当作 JSON 解析。

## 12. 交接验证与当前边界

建议验证场景：

1. 普通/管理员分别登录，未登录业务接口返回 401。
2. 教案生成、单步重做、AI 编辑、同步及批准后成稿；分别检查成功和模型不可用情况。
3. 保存后重新读取教案，核对 plan.id、request、modelAsset 和 warmupQuestions。
4. 课件生成、保存、单场景重做与导出；区分页面内清单和数据库清单。
5. 四视图首次 missing、生成 ready、缓存复用及 Blender 缺失。
6. multipart 上传缺文件、超限、类型不符；异步任务检查 queued、执行中、失败和完成分支。
7. 文件下载检查 MIME、文件大小和当前用户归属。
8. 普通用户访问管理员接口、读取其他用户模型/课件的拒绝行为。
9. 清理或刷新浏览器后，核对数据库保存和 localStorage 课堂恢复的不同结果。
10. 接口失败时页面展示真实错误或回退来源，避免把 200、editable=true 或存在 URL 当作审核通过。
